# 📐 Statistical Analysis

Statistical analysis was performed using **Statsmodels**.

### OLS Regression

Ordinary Least Squares (OLS) regression was used to investigate statistical relationships between the explanatory variables and Starting Salary.

The OLS model achieved:

* **R² = 0.899**
* **Adjusted R² = 0.889**

OLS is used for statistical interpretation, while Machine Learning models are used primarily for predictive evaluation.

# ⚠️ Project Limitations

The final Machine Learning dataset contains **44 observations**, while the SQL validation layer contains **400 records**.

The results should therefore be interpreted with caution.

The project identifies **associations and predictive patterns**, rather than causal relationships.

Starting Salary is used as a measurable proxy for career success.

The dataset does not directly measure whether an individual has learned SQL, Python, Tableau or Data Analytics.

Therefore, the project cannot directly prove that learning Data Analytics causes higher salaries.

A larger and more diverse dataset would provide stronger evidence and improve the generalizability of the results.
